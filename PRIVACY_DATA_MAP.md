# Privacy data map

Evidence date: 2026-08-25. This inventory covers the Expo app, Full Chat and Lite web clients, the Bun/Hono API, SQLite/Redis storage, the operator dashboard, and configured processors. It is the source of truth for the public privacy policy and both store worksheets.

## Apple privacy manifest evidence

The final generated app manifest declares no tracking; the nine collected-data categories in the worksheet above; and app-scoped `UserDefaults` reason `CA92.1`. The signed buildNumber 12 IPA contained 13 valid app/dependency manifests and the aggregate accessed-API categories File Timestamp (`C617.1`), User Defaults (`CA92.1`) and System Boot Time (`35F9.1`), with tracking disabled. Build 12 was created before the app-level collected-data declarations were added and is therefore superseded. Inspect the replacement archive and use Xcode's generated privacy report before App Store submission.
