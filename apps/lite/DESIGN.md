# Lite 디자인 시스템

## 적용 범위와 우선순위

이 문서는 `apps/lite` 전용 디자인 기준이다. Lite 화면을 수정할 때는 저장소 루트의 `DESIGN.md`보다 이 문서를 우선한다.

Lite는 일반 litechat 브랜드 화면이 아니라 스프레드시트 작업 화면처럼 보이는 Excel 스타일 인터페이스를 유지한다. 루트 디자인 시스템의 브랜드 블루, 로고 표현, 둥근 카드, 글래스 효과는 Lite에 적용하지 않는다.

## 디자인 목표

- 첫 화면부터 Excel 문서처럼 인식되는 시각 언어를 유지한다.
- 제목줄, 리본, 셀 격자, 행·열 머리글, 시트 탭, 상태줄, 수식 입력줄의 구조를 일관되게 사용한다.
- 채팅 상태는 별도의 말풍선보다 셀 위치, 행 선택, 텍스트 굵기로 구분한다.
- 장식보다 정보 밀도와 작은 초기 전송량을 우선한다.
- 모바일에서는 한 번에 한 열만, 768px 이상에서는 목록과 상세 열을 함께 표시한다.

## 색상 팔레트

| 역할 | 값 | 사용처 |
| --- | --- | --- |
| Excel 제목줄 | `#217346` | 브라우저 테마 컬러, 최상단 제목줄 |
| Excel 강조색 | `#107C41` | 기본 버튼, 활성 탭, 포커스 테두리, 현재 사용자 |
| 선택 행 | `#E7F1EC` | 활성 목록 행과 눌림 상태 |
| 하이퍼링크 | `#0563C1` | 이미지 파일 링크 |
| 오류 | `#CC0000` | 오류 메시지, 읽지 않은 수량 |
| 기본 캔버스 | `#FFFFFF` | 시트, 입력 필드, 셀 배경 |
| 기본 텍스트 | `#222222` | 본문과 오버레이 텍스트 |
| 강한 보조 텍스트 | `#444444` | 리본, 헤더, 참조 셀 |
| 보조 텍스트 | `#555555` | 열·행 머리글, 상태줄 |
| 약한 보조 텍스트 | `#666666` | 시간, 설명, 수식 기호 |
| 입력 테두리 | `#8A8A8A` | 입력 필드와 보조 버튼 |
| 강한 구분선 | `#B0B0B0` | 데스크톱 목록·상세 분할선 |
| 기본 구분선 | `#D4D4D4` | 셀 격자, 리본과 상태 영역 경계 |
| 그룹 헤더 | `#E8E8E8` | 목록 그룹 헤더 |
| 리본·거터 | `#F3F3F3` | 리본, 시트 탭, 행 번호 거터 |
| 보조 표면 | `#F9F9F9` | 채팅 헤더와 이모지 영역 |
| 미디어 오버레이 | `rgba(0, 0, 0, 0.75)` | 이미지·카메라 오버레이 |

`#0066CC`, `#0071E3` 등 루트 `DESIGN.md`의 브랜드 블루는 Lite에서 사용하지 않는다.

## 타이포그래피

기본 글꼴 스택은 다음 순서를 유지한다.

```css
Calibri, 'Segoe UI', 'Malgun Gothic', 'Apple SD Gothic Neo', sans-serif
```

- 기본 크기와 행간: `13px / 1.45`
- 셀 본문: `10px / 1.5`
- 행·열 머리글과 상태 정보: `9px`~`12px`
- 인증 제목: `24px`, `font-weight: 600`
- 수식 기호 `fx`: Georgia italic bold
- 숫자, 시간, 사용량은 `font-variant-numeric: tabular-nums`를 사용한다.

## 격자와 치수

| 토큰 | 값 | 의미 |
| --- | --- | --- |
| `--cw` | `64px` | 기본 Excel 열 폭 |
| `--rh` | `20px` | 기본 행 높이와 빈 시트 눈금 간격 |
| `--g` | `28px` | 행 번호 거터 |
| `--nw` | `84px` | 목록 이름·시간 열 |
| `--mw` | `604px` | 대화 본문의 최대 격자 폭 |

격자선은 `#D4D4D4` 1px을 사용하며 셀, 행 번호, 빈 시트 배경에서 동일한 간격을 유지한다. 메시지 폭은 `--cw`의 정수 배수로 맞춰 셀 경계와 어긋나지 않게 한다.

## 구성 요소

### Excel 크롬

- 제목줄은 `#217346` 배경과 흰색 텍스트를 사용한다.
- 리본과 시트 탭은 `#F3F3F3`을 사용하고 활성 항목만 `#107C41`로 강조한다.
- 활성 시트는 아래쪽 2px 녹색 선으로 표시한다.
- 상태줄은 작은 글자와 탭형 숫자를 사용한다.

### 입력과 버튼

- 기본 버튼: `#107C41` 배경, 흰색 텍스트, `2px` 모서리.
- 보조 버튼과 입력: 흰색 배경, `#8A8A8A` 1px 테두리, `2px` 모서리.
- 입력 포커스: 테두리만 `#107C41`로 바꾼다.
- 과도한 그림자, 그라데이션, 알약형 모서리를 추가하지 않는다.

### 채팅

- 메시지는 말풍선 대신 값이 입력된 셀로 표시한다.
- 보낸 메시지와 받은 메시지는 색상이 아니라 좌우 위치로 구분한다.
- 이미지 메시지는 `#0563C1` 밑줄 링크로 표현한다.
- 입력 영역은 Excel 수식 입력줄처럼 참조 셀, `fx`, 텍스트 영역, 전송 동작 순서로 배치한다.

## 반응형 동작

- 768px 미만: 목록 또는 채팅 한 화면만 표시한다. 채팅 화면에서는 뒤로 가기 컨트롤을 제공한다.
- 768px 이상: 목록은 300px 고정 폭, 상세 영역은 나머지 공간을 사용한다.
- 안전 영역 inset을 제목줄과 하단 입력·상태 영역에 반영한다.
- 작은 화면에서도 셀 격자 간격과 행 번호 거터는 축소하지 않는다.

## 구현 규칙

- 스타일의 단일 구현 원본은 `apps/lite/src/style.css`이다.
- `apps/lite/src/index.html`의 `theme-color`는 `#217346`을 유지한다.
- 루트 디자인 토큰이나 다른 앱의 CSS를 가져오지 않는다.
- 새 색상을 추가하기 전에 기존 팔레트로 표현할 수 있는지 먼저 확인한다.
- UI 변경 후 `bun run --cwd apps/lite build`의 10KB Brotli 예산과 데스크톱·모바일 렌더링을 함께 검증한다.
- 이 문서와 구현이 달라지는 변경은 둘을 같은 커밋에서 갱신한다.
